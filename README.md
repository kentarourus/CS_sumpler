# 🎭 CS_sumpler - 学校演劇用 効果音・せりふ再生アプリ

> **舞台袖の暗闇でも、絶対に失敗しない・迷わない。**  
> キーボード操作で効果音・せりふ・BGMをポン出しできる、学校演劇・舞台公演向けWebアプリケーションです。  
> サーバー不要の静的サイトとして設計されており、**GitHub Pagesですぐに公開・無料運用**できます。

---

## 🌟 主な特徴

- ⚡ **Web Audio API による高機能再生エンジン**
  - **ポリフォニック同時再生**: BGMを流しながら効果音やせりふを重ねて再生可能
  - **一時停止＆止めた位置からの再開 (Pause & Resume)**: 台本の中断やハプニング時も安心
  - **再生速度変更 (0.25x 〜 4.0x)** & **ピッチ変更 (±2オクターブ / cents単位)**
  - **多重押下制御（重ね再生 ON/OFF）**: 音声ごとに「重ね再生 ON（連打時に音を重ねて鳴らす）」「重ね再生 OFF（連打時は頭出し・最初から鳴らし直す）」「トグル（再生/停止）」「排他（無視）」をライブラリや設定画面からワンクリックで切り替え可能
  - **幅広い音声フォーマット対応**: MP3, WAV, OGG, AAC/M4A, FLAC, WebM 等
- 🎛️ **現在再生中音声の集中管理マネージャー (Now Playing Deck)**
  - 再生中の音声をリアルタイムで一覧表示（進捗バー・経過時間・音量スライダー）
  - 音声ごとに「⏸ 一時停止」「▶ 再生再開」「⏹ 個別停止」「個別音量微調整」をワンクリックで実行可能
  - 全体に対する「⏸ 全一時停止」「▶ 全再開」「⏹ 全停止」の一括操作にも対応
  - 設定モード・本番モードの双方で常時モニター可能
- 📜 **幕・場面ごとのキュー順送り（Space / Enter）**
  - 「第1幕」「第2幕」「エピローグ」など、場面ごとに独立したキューリストを管理
  - `Space` または `Enter` キーを押すだけで音声を再生し、自動で次のキューへ進行
  - `↑` `↓` キーで音を鳴らさずにカーソルの確認・巻き戻しが可能（リハーサル・頭出し対応）
- 🎹 **直接キー割り当て（いつでも鳴らせるSEゾーン）**
  - 数字キー（`1`〜`0`）や英字キー（`Q`〜`L`）、**外付けUSBテンキー**にSEを固定割り当て
  - 台本の進行状況に関係なく、緊急のSEや頻出音をワンキーで即座に発報
- 🚨 **万全の安全機能（非常停止）**
  - `Esc` キーで**全音即時停止（パニックストップ）**（プチノイズ防止の微小フェード対応）
  - `Backspace` キーで**直前に鳴らした音のみ停止**
  - `M` キーで**マスターミュート / ミュート解除**
  - テキスト入力中は通常ショートカットを自動サスペンド（誤爆防止、ただし `Esc` は常時有効）
- 💾 **ブラウザ内完全保存（IndexedDB）＆一括エクスポート/インポート**
  - サーバーを使わず、音声データ本体と設定を操作者のブラウザ内に自動永続化
  - プロジェクト設定＋音声ファイルをまとめた単一ファイル（`.theatersound` / JSON）でPC間移行・バックアップが可能
- 🌓 **暗所最適化UI（設定モード / 本番モード）**
  - **設定モード**: ドラッグ＆ドロップによる音声登録、キーボードマップ視覚設定、キュー編集
  - **本番モード**: 黒背景＋大文字表示、再生中バーのリアルタイム進捗モニター、舞台袖で眩しくない高コントラスト設計

## 🚀 使い方・導入方法

### 方法1: 自分の学校のリポジトリとして GitHub Pages で公開（推奨）

1. このリポジトリを **Fork（フォーク）** します。
2. Fork先の GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を `main` / `root` に設定して **Save** します。
4. 数十秒で発行されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）にアクセスするだけで、部員全員が利用できます！

### 方法2: ローカルPCで動かす（オフライン・練習用）

Node.js がインストールされている場合、以下のコマンドで起動できます。

```bash
# リポジトリをクローン
git clone https://github.com/kentarourus/CS_sumpler.git
cd CS_sumpler

# 簡易HTTPサーバーで起動
npx http-server -p 8080
```
ブラウザで `http://localhost:8080` を開きます。

## 📖 操作ガイド

### 1. 初回アクセス時
画面中央の **「クリックして音声を有効化」** を1回クリックします。  
（ブラウザの自動再生ポリシー制限を解除し、以降はキーボードのみで操作可能になります）

### 2. 設定モード（準備・仕込み）

```
┌───────────────────────────────────────────────────────────────┐
│ [プロジェクト名]        🔊 [=====音量=====]  [💾保存] [📤] [📥] │
├─────────────────┬─────────────────────────────┬───────────────┤
│ 音声ライブラリ  │ キューリスト（台本順）      │ キー割り当て  │
│ [📁 D&Dで追加]  │ ◀ [第1幕 ▼] ▶ [＋] [✕]      │ 1 2 3 4 5 ... │
│ [📄ファイル][📁フォルダ]│ 1. 開幕BGM                  │ Q W E R T ... │
│ ・雷.mp3        │ 2. せりふ「朝が来た」       │ [テンキー 789]│
│ ・チャイム.wav  │ 3. ドアベルSE               │               │
│ ・拍手.mp3      │                             │               │
└─────────────────┴─────────────────────────────┴───────────────┘
```

1. **音声の登録**:
   - **フォルダごとドロップ**: 劇用効果音が入ったフォルダをそのままドロップすると、サブフォルダ内も含めて音声ファイルを一括読み込みします。
   - **ボタンから選択**: 「📄 ファイル選択」または「📁 フォルダ選択」ボタンからまとめて選択することも可能です。
2. **キューの作成**:
   - 音声アイテムをキューリストへドラッグ＆ドロップ、または「＋ キュー追加」をクリックします。
   - ⚙ボタンを押すと、キューごとの音量・再生速度・ピッチ・演出メモを設定できます。
   - ▲▼ボタンで順番を台本通りに並べ替えます。
3. **直接キーの割り当て**:
   - 右側のキーボードマップで任意のキーをクリックし、鳴らしたい音声を選択します。
4. **幕・場面の追加**:
   - ドロップダウン横の「＋」ボタンで「第2幕」「カーテンコール」などの幕を追加できます。
5. **保存**:
   - 右上の「💾 保存」をクリックするとブラウザに保存されます。「📤」でファイルとして書き出せば他のPCにも共有できます。

### 3. 本番モード（公演中）

画面右上の切り替えスイッチで **「本番」** を選択します。

```
┌───────────────────────────────────────────────────────────────┐
│                           第 1 幕                             │
│                           12 / 48                             │
│                                                               │
│                   次に Space で再生：                         │
│                    「ドアが閉まる音」                         │
│                                                               │
│  ───────────────────────────────────────────────────────────  │
│  直接キー: [1 雷鳴] [2 チャイム] [3 拍手] [Q 足音] ...        │
│                                                               │
│  再生中: 開幕BGM  [====== 45% ======] 0:32                    │
│                                                               │
│                   [ ■ 全停止（Esc） ]                         │
└───────────────────────────────────────────────────────────────┘
```

## ⌨️ キーボードショートカット一覧

| キー | 機能 | 説明 |
|---|---|---|
| `Space` / `Enter` | **キュー再生 / 進行** | 次のキューを再生し、自動でカーソルを1つ進めます |
| `↓` (Arrow Down) | **キュー送り（無音）** | 音を鳴らさずに次のキューを確認・スキップします |
| `↑` (Arrow Up) | **キュー戻し（巻き戻し）** | 音を鳴らさずに前のキューへ戻します（誤操作時のリカバリ） |
| `Esc` | **非常停止 (Panic Stop)** | 再生中のすべての音声を即座に停止します |
| `Backspace` | **直前の音のみ停止** | 最後に鳴らした音声だけを止めます（BGMを残してSEだけ止める等） |
| `P` | **一時停止 / 再開** | 再生中の音声を一時停止、または止めた位置から再開します |
| `M` | **マスターミュート** | 全体の音声をミュート / ミュート解除します |
| `PageDown` | **次の幕へ** | 次の幕・場面のキューリストに切り替えます |
| `PageUp` | **前の幕へ** | 前の幕・場面のキューリストに切り替えます |
| `1` 〜 `0` | **直接SE再生 1〜10** | 割り当てた効果音を即座に再生します |
| `Q` 〜 `L` | **直接SE再生 QWERTY** | 割り当てた効果音を即座に再生します |
| テンキー `1` 〜 `9` | **外付けテンキーSE再生** | 外付けUSBテンキーから効果音を即座に再生します |

> ※ キューリスト上の任意の行をクリックすることで、リハーサル時の途中頭出しも可能です。

## 🛠️ システム構成・技術仕様

- **アーキテクチャ**: Vanilla JavaScript (ES Modules) + Web Audio API + IndexedDB
- **外部依存**: なし（ビルドステップ不要、CDNや外部通信なしで完全動作）
- **動作環境**: Google Chrome, Microsoft Edge, Safari, Firefox の最新版
- **テストスイート**: 83項目の単体・統合テストを完備 (`node test/runTests.js`)

```
CS_sumpler/
├── index.html               # メインHTML
├── index.css                # 暗所最適化デザインシステム
├── app.js                   # UIコントローラー
├── package.json             # プロジェクト設定
├── src/
│   ├── index.js             # コアモジュール公開エントリ
│   ├── types/
│   │   └── models.js        # データモデル・定数
│   └── core/
│       ├── AudioEngine.js   # Web Audio API 再生エンジン
│       ├── AudioTrack.js    # 個別ボイス制御（速度・ピッチ・ポーズ/レジューム）
│       ├── CueManager.js    # 幕・場面・キューリスト管理
│       ├── KeymapManager.js # 物理キーバインディング・安全機能
│       ├── StorageManager.js# IndexedDB永続化・バンドル入出力
│       └── TheaterSystem.js # 統合ファサード
└── test/
    └── runTests.js          # 自動検証テストスイート
```

## ⚠️ 音声素材・著作権に関する注意

本アプリケーション自体には音声ファイルは同梱されていません。
公演で使用する効果音・BGM・音声ファイルは、以下のいずれかをご利用ください。

1. フリー効果音・BGM素材サイト（利用規約で演劇・公演利用が許可されているもの）
2. 著作権フリー・パブリックドメイン音源
3. ご自身・部員で録音・作成したオリジナル音声
